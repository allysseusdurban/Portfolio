# Next.js portfolio

Install dependencies and start the development server from this folder.

```sh
npm install
npm run dev
```

Open the local URL printed by Next.js, usually http://localhost:3000.

Edit `app/portfolio.js` to add your name, introduction, bio, skills, and email. When you fill in the email field, the contact section displays an email button. Replace the two sample projects with your own entries and place their artwork under `public/projects/`.

Run `npm run build` to create a production build and `npm start` to serve it locally.

## Sample artwork

The two WebP covers were created with the built-in ImageGen tool using these prompts.

- `public/projects/form-field.webp` — Use case: product-mockup. Landscape portfolio cover for a fictional design studio web concept, editorial architectural photography. A minimal rectangular beige concrete pavilion frames a desert mountain range and a strip of pale blue sky. Refined modernist architecture with a large dark doorway, hard afternoon sunlight and dramatic clean shadows, beautiful warm sandy limestone texture. Compose for a wide 3:2 crop, image bleeds to every edge. Warm desaturated beige and natural olive. No people, no graphics, no text, no watermarks.
- `public/projects/signal.webp` — Use case: ui-mockup. Landscape 3:2 portfolio cover photograph for a fictional listening app called Signal. A modern black smartphone floating slightly tilted over a deep cobalt studio backdrop, its glossy screen shows a stylish minimal dark music player with vivid pink and cobalt abstract album art, a simple progress bar and familiar playback controls. Dramatic blue studio lighting, refined editorial product photography, full phone comfortably in frame, center-right composition, softly reflected light and generous breathing room. No legible writing, external logos or watermarks.
